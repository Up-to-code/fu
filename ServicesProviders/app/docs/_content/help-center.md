# مركز المساعدة

## الهدف

تسهيل الوصول إلى الإجابات السريعة، مع توجيه المستخدم إلى التوثيق التفصيلي داخل التطبيق.

## أين تجدها

- المساعدة: `/help`
- التوثيق: `/docs`

## كيف تستخدم المساعدة بفعالية

1. ابدأ من صفحة المساعدة لأسئلة الاستخدام المتكررة.
2. انتقل إلى التوثيق التفصيلي للموضوع (مثل لوحة التحكم أو إنشاء الخدمات).
3. استخدم الروابط السياقية داخل الشاشة (أيقونة المساعدة) للوصول مباشرةً إلى صفحة التوثيق المناسبة.

## نطاق الأسئلة المتكررة (مقترح)

- إنشاء خدمة جديدة وإضافة خيارات مسعّرة
- متابعة المواعيد عبر التقويم
- إدارة الحساب البنكي والمحفظة
- الرد على رسائل العملاء ورفع الملفات
- فهم مسار الحجز وتأكيد الدفع وتأكيد الإكمال
