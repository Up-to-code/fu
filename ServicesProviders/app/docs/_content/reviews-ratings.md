# التقييمات والمراجعات (نجوم + تعليق)

## الهدف

بعد تأكيد إكمال الخدمة، يقيّم العميل جودة الخدمة ويضيف تعليقاً اختيارياً. ينعكس ذلك على سمعة مقدم الخدمة ويساعد في تحسين مستوى الخدمة.

## متطلبات تجربة المستخدم

- يظهر نموذج التقييم بعد تأكيد الإكمال مباشرةً
- تقييم بالنجوم من 1 إلى 5
- تعليق نصي اختياري
- إمكانية رد مقدم الخدمة (عند تفعيلها)
- مسار تبليغ/إخفاء للمحتوى المسيء أو غير اللائق

## نموذج البيانات (مقترح)

```txt
Review
- id
- bookingId
- serviceId
- customerId
- providerId
- stars (1..5)
- comment (اختياري)
- createdAt
- status (published/hidden/reported)
```

## سياسات النزاهة والجودة

- يمنع تضمين معلومات شخصية حساسة داخل التعليقات.
- يحق للإدارة إخفاء التعليقات المخالفة وفق سياسة الاستخدام.
- يفضل إتاحة “تبليغ” للمراجعات مع سبب مختصر (إساءة/ابتزاز/معلومات مضللة).

## نقاط التكامل داخل التطبيق

- لوحة التحكم: عرض متوسط التقييم وعدد المراجعات
- صفحة الخدمة: عرض قائمة المراجعات وأبرز التعليقات (عند تفعيل صفحة تفاصيل الخدمة)
