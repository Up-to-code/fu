# الشروط والخصوصية والاستخدام

## الهدف

تلخيص الصفحات القانونية داخل التطبيق وتوضيح ما يجب على مقدم الخدمة معرفته لضمان الامتثال وسياسة التعامل مع البيانات والمحتوى.

## الصفحات ذات الصلة

- الشروط والأحكام: `/terms`
- سياسة الخصوصية: `/privacy`
- سياسة الاستخدام: `/usage`

## مبادئ عامة

- يجب احترام خصوصية العملاء وعدم مشاركة بياناتهم خارج نطاق تنفيذ الخدمة.
- يجب تجنب طلب معلومات حساسة لا حاجة لها (مثل بيانات بنكية للعميل).
- يمنع رفع محتوى مخالف أو مسيء عبر الرسائل أو ملفات التسليم.

## التعامل مع البيانات

- استخدم المرفقات والرسائل ضمن المنصة فقط عند تبادل ملفات العمل.
- عند تفعيل التخزين الخارجي، يجب أن تكون روابط الرفع موقعة وأن تكون الصلاحيات مقيدة زمنياً.
