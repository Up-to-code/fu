# الإشعارات (التدفق وواجهة المستخدم)

## الهدف

تضمن الإشعارات اطلاع العميل ومقدم الخدمة على الأحداث المهمة طوال دورة حياة الخدمة، مع تقليل الحاجة للمتابعة اليدوية.

## أين تجدها

- الإشعارات: `/notifications`

## أنواع الإشعارات (مقترح موحّد)

- **تشغيلي**: حجز جديد، قبول الحجز، بدء التنفيذ
- **زمني**: تذكير قبل الموعد، تنبيه اقتراب التسليم
- **مالي**: تأكيد الدفع، أهلية الصرف، صرف الأرباح
- **جودة/ثقة**: تقييم جديد، تعليق/مراجعة

## ربط الأحداث بالإشعارات (موصى به)

- إنشاء حجز → إشعار لمقدم الخدمة
- قبول الحجز → إشعار للعميل
- تأكيد الدفع → إشعار لمقدم الخدمة
- بدء التنفيذ → إشعار للعميل
- تحديث مرحلي → إشعار للعميل
- طلب تأكيد الإكمال → إشعار للعميل
- تأكيد الإكمال → إشعار لمقدم الخدمة
- صرف الأرباح → إشعار لمقدم الخدمة

## قنوات الإرسال

- داخل التطبيق (فوري)
- البريد الإلكتروني (عند تفعيله)
- الرسائل القصيرة (عند تفعيلها ودعم البلد)

## اعتبارات تشغيلية

- يجب احترام تفضيلات المستخدم داخل الإعدادات (تعطيل/تفعيل فئات محددة).
- يفضل تصنيف الإشعارات حسب الأولوية (عادية/عاجلة) لتجنب الإزعاج.
