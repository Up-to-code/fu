# دليل التصميم العصري للتوثيق

## مبادئ التصميم

### 1. البساطة
- استخدام أقل عدد من العناصر لتحقيق أقصى تأثير
- إزالة كل ما هو غير ضروري
- التركيز على المحتوى الأساسي

### 2. الوضوح
- تباين عالي للقراءة المثالية
- تسلسل هرمي واضح للمعلومات
- مساحة بيضاء كافية حول العناصر

### 3. التركيز
- تقليل التشتيت البصري
- توجيه الانتباه إلى ما هو مهم
- إزالة العناصر الزائدة

## نظام الألوان

### الألوان الأساسية
- **النص الأساسي**: `#111827` (رمادي غامق جداً)
- **النص الثانوي**: `#6B7280` (رمادي متوسط)
- **النص المميز**: `#000000` (أسود نقي)
- **الخلفية**: `#FFFFFF` (أبيض نقي)

### الألوان الداعمة
- **الحدود**: `#E5E7EB` (رمادي فاتح)
- **الخلفية الثانوية**: `#F9FAFB` (رمادي شاحب جداً)
- **الروابط**: `#111827` مع تسطير
- **الرمز البرمجي**: `#1F2937` على خلفية `#F3F4F6`

## نظام الخطوط

### التسلسل الهرمي للخط

#### العناوين الرئيسية (H1)
- الحجم: 48px (3rem)
- الوزن: 300 (خفيف)
- الخط: النظام الافتراضي
- المسافة بين الأسطر: 1.2

#### العناوين الثانوية (H2)
- الحجم: 36px (2.25rem)
- الوزن: 300 (خفيف)
- المسافة بين الأسطر: 1.3

#### العناوين الفرعية (H3)
- الحجم: 24px (1.5rem)
- الوزن: 300 (خفيف)
- المسافة بين الأسطر: 1.4

#### النص الأساسي
- الحجم: 18px (1.125rem)
- الوزن: 400 (عادي)
- المسافة بين الأسطر: 1.6
- أقصى عرض: 65-75 حرفاً

#### النص الثانوي
- الحجم: 14px (0.875rem)
- الوزن: 400 (عادي)
- المسافة بين الأسطر: 1.5

## نظام التباعد

### التباعد الأساسي
- **صغير جداً**: 4px (0.25rem)
- **صغير**: 8px (0.5rem)
- **متوسط**: 16px (1rem)
- **كبير**: 24px (1.5rem)
- **كبير جداً**: 32px (2rem)
- **ضخم**: 48px (3rem)

### التباعد الرأسي
- **بين الفقرات**: 24px
- **بين العناوين والنص**: 16px
- **بين الأقسام**: 48px
- **الهوامش العلوية**: 96px للصفحة الكاملة

### التباعد الأفقي
- **الهوامش الجانبية**: 24px على الجوال، 48px على المكتبي
- **أقصى عرض للمحتوى**: 768px للقراءة المثالية

## مكونات الواجهة

### الرأس (Header)
- الارتفاع: 64px
- الخلفية: شفافة مع تأثير blur
- الحدود: خط رفيع 1px
- الأزرار: نص فقط بدون خلفية

### التنقل الجانبي
- العرض: 256px
- المسافة من الأعلى: 80px
- الثبات: sticky
- التباعد: 24px داخلي

### جدول المحتويات
- المسافة بين العناصر: 8px
- التدرج: 16px للعناصر الفرعية
- الثبات: sticky مع مسافة 32px من الأعلى

### الأزرار
- **النص**: وزن 400، حجم 14px
- **التباعد**: 12px أفقي، 8px عمودي
- **الزوايا**: 6px مستديرة
- **الانتقالات**: 200ms ease-out

## مبادئ التجاوب

### الجوال (أقل من 768px)
- عرض كامل للمحتوى
- جدول المحتويات مخفي
- خط أكبر للقراءة (20px)
- تباعد أكبر للمس (48px)

### التابلت (768px - 1024px)
- عرض محتوى 90%
- جدول المحتويات في أسفل
- تكيف مع اتجاه الشاشة

### المكتبي (أكثر من 1024px)
- تخطيط شبكي ثابت
- جدول المحتويات الجانبي
- أقصى عرض للنص 768px

## قواعد الكتابة

### البساطة في اللغة
- استخدام الجمل القصيرة (أقل من 20 كلمة)
- الفعل المباشر في البداية
- تجنب الكلمات المعقدة
- استخدام الأمثلة الواضحة

### التسلسل الهرمي
- عنوان واضح لكل قسم
- فقرة افتتاحية مختصرة
- نقاط رئيسية مرتبة
- خلاصة عند الحاجة

### التنسيق البصري
- مسافة كافية بين العناصر
- استخدام القوائم للتسلسل
- تسطير الروابط فقط
- تجنيد الألوان الزاهدة

## أمثلة التطبيق

### قبل وبعد

**قبل (معقد):**
```
تُعد عملية إنشاء الحجز وإدارتها من خلال نظامنا الإلكتروني المتطور واحدة من أهم المزايا التي نقدمها للمستخدمين، حيث تتيح لهم إمكانية حجز الخدمات بطريقة سهلة ومريحة مع توفير العديد من الخيارات والإعدادات المتقدمة.
```

**بعد (بسيط):**
```
أنشئ حجزك بسهولة. اختر الخدمة والموعد المناسب. النظام يحسب السعر ويؤكد التوافق.
```

### مكونات التوثيق

#### عنوان رئيسي
```html
<h1 class="text-5xl font-light text-gray-900 mb-8">
  تدفق الخدمة
</h1>
```

#### فقرة نصية
```html
<p class="text-lg text-gray-700 leading-relaxed mb-6">
  نظامنا يربط بين العملاء ومقدمي الخدمات بطريقة سلسة.
</p>
```

#### قائمة بسيطة
```html
<ul class="space-y-3 text-gray-700">
  <li class="flex items-start">
    <span class="text-gray-400 mr-3">•</span>
    اختيار الخدمة المناسبة
  </li>
</ul>
```

## التوثيق التقني

### المتغيرات CSS
```css
:root {
  --color-text-primary: #111827;
  --color-text-secondary: #6B7280;
  --color-background: #FFFFFF;
  --color-border: #E5E7EB;
  --font-size-base: 1.125rem; /* 18px */
  --line-height-base: 1.6;
  --spacing-unit: 1rem; /* 16px */
  --max-width-text: 48rem; /* 768px */
}
```

### الكلاسات الأساسية
```css
.text-primary { color: var(--color-text-primary); }
.text-secondary { color: var(--color-text-secondary); }
.bg-primary { background-color: var(--color-background); }
.border-subtle { border-color: var(--color-border); }
.max-w-readable { max-width: var(--max-width-text); }
```

## اختبار القراءة

- **سهولة القراءة**: مقياس Flesch (60-80)
- **طول الجملة**: متوسط 15-20 كلمة
- **الكلمات المعقدة**: أقل من 10%
- **المسافة بين الأسطر**: 1.5-1.7

### أدوات القياس
- WebAIM Contrast Checker
- Hemingway Editor
- Readable.com
- Flesch Reading Ease

- فحص التباين شهرياً
- تحديث المحتوى ربع سنوياً
- اختبار التجاوب عند التغييرات
- جمع ملاحظات المستخدمين

### تحسين مستمر
- تقليل الكلمات بنسبة 20% في كل مراجعة

- تحسين التدفق المنطقي
