# Backend Workflows

## Booking Creation

1. Validate service + selected options
2. Persist booking
3. Create conversation thread
4. Notify provider
5. Create calendar event

## Payment Processing

1. Create payment intent
2. Confirm payment
3. Webhook updates booking payment state
4. Notify provider

## Service Completion & Payout

1. Provider requests completion
2. Customer confirms completion
3. Optional dispute window
4. Trigger payout release
5. Notify provider
