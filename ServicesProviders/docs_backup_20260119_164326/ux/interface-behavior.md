# UI/UX Behavior Guidelines

## Service Visibility

- Services appear in the provider dashboard under “My Services”.
- Active bookings appear in the dashboard calendar and active-work panel.

## Settings Integration

- Settings should include notification preferences and service availability controls.
- Storage/stock-related settings must not appear for service providers.

## Ratings & Reviews

- After completion, prompt for rating (stars) and optional comment.
- Show average rating in dashboard summary.

## Help Center

- Help Center should answer common service-provider questions.
- FAQ entries should guide users to the relevant screen paths.
