# Service Details Page Specification

## Goal

Present all relevant service information and allow customers to initiate booking.

## Required Elements

- Title and description
- Price range (min/max)
- List of priced options
- Provider profile summary
- Reviews summary + recent reviews
- Booking CTA (schedule + options)

## Notes

Service listing currently exists for providers under `app/(dashboard)/services/*`. This spec describes a customer-facing details view to be built later.
