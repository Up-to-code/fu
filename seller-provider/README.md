Seller Provider is a Next.js dashboard for vendors (products, orders, organization management) backed by Convex and Better Auth.

## Getting Started

### 1) Install

```bash
npm install
```

### 2) Configure Environment

Follow [ENV_SETUP.md](./ENV_SETUP.md) and create `seller-provider/.env.local` with the required variables.

### 3) Run

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 4) Tests

```bash
npm test
```
